# cmk:requirements

## What
Skill that drafts and iterates requirements documents (PRDs) — the upstream "what and why" before any technical design. Synthesizes from conversations, research notes, Notion/Google Doc links, and `docs/knowledge/` entries.

## Where
- Skill body: `skills/requirements/SKILL.md` — sections `Input`, `Workflow: Create`, `Workflow: Iterate`, `Output`, `Links`.
- Placement rules: `skills/requirements/references/requirements-conventions.md`.
- Section template: `skills/requirements/references/requirements-template.md`.
- Output template (rendered shape): `docs/templates/requirements.md`.
- Default placement: `docs/requirements/<topic>.md` — see `docs/requirements/README.md`.
