# cmk:feature-spec

## What
Skill that drafts and iterates per-feature specifications — implementation-level detail for one feature. Sits downstream of PRD and system-design; cross-checks for upstream conflicts on iterate.

## Where
- Skill body: `skills/feature-spec/SKILL.md` — sections `Input`, `Workflow: Create`, `Workflow: Iterate`, `Output`.
- Placement rules: `skills/feature-spec/references/spec-conventions.md`.
- Section template: `skills/feature-spec/references/feature-spec-template.md`.
- Output template (rendered spec shape): `docs/templates/feature-spec.md`.
- Default placement of generated specs: `docs/specs/{NNNN}-{feature-name}/spec.md` — see `docs/specs/README.md`.
