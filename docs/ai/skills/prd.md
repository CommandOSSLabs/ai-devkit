# cmk:prd

## What
Skill that drafts and iterates Product Requirements Documents — the upstream "what and why" before any technical design. Synthesizes from conversations, research notes, Notion/Google Doc links, and `docs/knowledge/` entries.

## Where
- Skill body: `skills/prd/SKILL.md` — sections `Input`, `Workflow: Create`, `Workflow: Iterate`, `Output`.
- Placement rules: `skills/prd/references/prd-conventions.md`.
- Section template: `skills/prd/references/prd-template.md`.
- Output template (rendered PRD shape): `docs/templates/PRD.md`.
- Default placement: `docs/PRD.md`.
