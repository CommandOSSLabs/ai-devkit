# Validator: standards/design-tokens (structural only)

Pass/fail only. Fail if missing required headings (Purpose and boundary; Stack
(allowed); Token source of truth; Color roles; Type & spacing scales; Numeric
floors; Forbidden; Component inventory), empty slots without `None — <reason>`,
empty tables without data row or None, placeholders TBD/TODO/.../lorem,
unresolved Blocker:, or missing `Status: Approved` for write readiness. No
semantic judgment.
