# Project Overview

[`/docs`](./docs) is the source of truth for this repository.

It exists for two purposes:
- Store essential and critical documentation for this repository
- Organize living requirements, design, decisions, and rules used during development

Start in [`docs/README.md`](./docs/README.md) for navigation and task routing.

## Pull Requests

Always load and follow the [`pr-writing`](./skills/pr-writing/SKILL.md) skill (`~/.agents/skills/pr-writing/SKILL.md`) whenever opening or updating a pull request, and ship updates through a pull request written with `pr-writing` (problem in one paragraph, grouped changes, real verification evidence, details/trade-offs, and a 2–3 sentence ELI5, with zero AI attribution).
